# 🐧 Hack The Box — Linux Easy Machines

This repository contains **structured, step-by-step write-ups** for **Linux Easy Hack The Box machines**.

The goal of this repo is to:
- Build **strong enumeration habits**
- Follow a **repeatable attack methodology**
- Clearly document **why something worked**, not just *what* worked

All machines are solved **without spoilers** and follow a **beginner-friendly but professional format**.

---

Each machine has its own folder with:
- A dedicated `README.md` write-up
- Supporting screenshots (only where required)

---

## 🧠 Methodology Used

All machines follow the same **write-up order**:

1. Initial Enumeration
2. Service Analysis
3. Exploitation
4. Privilege Escalation
5. Lessons Learned

This ensures consistency and avoids random or guess-based exploitation.

---

## ⚠️ Disclaimer

- These write-ups are for **educational purposes only**
- Do **NOT** use these techniques on systems you do not own or have permission to test
